Start Production Runner

Issue remote desired state to start the Production Runner daemon on the worker plane. The target campaign must be in RUNNING status.

Stop Production Runner

Requests graceful termination of the Production Runner daemon. Any message currently in-flight will conclude cleanly to avoid ambiguous outcomes.

Activate Emergency Stop

Immediately sets the killswitch flag. All future queue message claims are blocked across the entire system (<500ms target latency).

Resume Dispatch Operations

Disarms the emergency stop flag, allowing the runner and queue worker to resume claiming staged messages. Requires ADMIN or OWNER privilege.
